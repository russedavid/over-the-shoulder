What the engineering has to get right

Context that remains accountable

Observed fragments, complete selected files, spoken claims, and proposals retain distinct meanings and sources.

Updates that respect ongoing work

Requests use stable snapshots. Late answers, pinning, task changes, and manual capture are handled explicitly.

Authority outside the model

Optional inspection uses a bounded read-only tool set. Mentioning a file or suggesting an action does not grant permission.
